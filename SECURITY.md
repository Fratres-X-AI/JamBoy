# Security Policy

## Reporting a vulnerability

Please report security issues privately to the maintainers of the
[Fratres-X-AI/JamBoy](https://github.com/Fratres-X-AI/JamBoy) repository
(GitHub Security Advisories preferred).

Do **not** open a public issue that includes:

- SSH hosts, ports, proxy usernames, or private keys
- Cloud API tokens, `.env` files, or credentials
- Live pod / infrastructure identifiers

## Scope

JamBoy is navigation research software. Reports related to unsafe defaults,
credential leakage in docs/scripts, or remote code execution in tooling are
welcome. Flight-worthiness and regulatory compliance are out of scope for this
policy.
