# Roadmap

JamBoy Phase 1 focuses on **stable simulation + hardware drop-in readiness**.
Items below are planned; see [`CAPABILITIES.md`](CAPABILITIES.md) for the
current DONE / PARTIAL / PLANNED matrix.

## Near term

- Closed-loop PX4 SITL + Gazebo downward camera (`gazebo/` is a stub today)
- Camera–IMU hardware time sync
- Stronger terminal guidance (lightweight detector beyond CSRT stub)
- Real mission GeoTIFF + NIR-speckle mapping workflow docs

## Later

- Power / thermal profiling on Jetson-class hardware
- Map update / distribution pipeline
- Field flight test campaign on attritable airframes

## Out of scope

Full autonomous strike capability, targeting, and ROE layers.
